Wooden Overhang Modular Kit by Trey Ramm
----------------------------------------
Thank you for downloading this kit! I hope that you'll find it 
useful for your own projects or learning more about game
development :)

All meshes are UV unwrapped for the textures provided in the ZIP file. 
To use the material, just add the textures to whatever 3D program you're using
then assign the material to the meshes.

The grid was created in Maya with a unit size of 1cm. The main pieces are 
100cm wide and 200cm tall.

If you use these in a project, please send me a link! I'd love to see what
other people are using these assets for.

Good luck and have fun:
Trey Ramm
