# Uji Windows Phase 4

Jalankan `Review-Phase4.cmd`, lalu **Continue** pada menu. Launcher memakai save terpisah `Phase4Review` di persistentDataPath; save kampanye utama tidak ditimpa. Run baru dimulai di Kos sore dengan 37% baterai, Sanity23 dan saldo0 untuk menguji jalur gratis. Colokan dan pilihan menenangkan diri pada PC bersifat eksplisit; tekan pintu/kunci motor untuk berangkat. Untuk mengulang dari awal, arsipkan folder save khusus tersebut, bukan save utama.

Kontrol mengikuti Pengaturan: RMB ditahan untuk kamera, V OTS/FP, X Selfie, Q AR, R UV, T Thermo, C ketuk analyzer/tahan EVP, E interaksi/tahan tindakan, F layar, B powerbank, H kemenyan. Flare G ditolak tanpa menghabiskan stok. Aktifkan GLITCH: REDUKSI bila diperlukan.

Rute: motor → tiga simpang (jejak fisik UV mengalahkan chat) → Pendopo. Investigasi Utara/Thermo, Timur/foto AR, Barat/EVP6detik bebas urutan; ambil pusaka masing-masing secara terpisah. Simpan dokumen dan konfirmasi Jurnal. Sumur/saluran mengisi Kendi. Kitab dan kacamata ada di meja samping Pendopo. Pasang tiga pusaka, lalu aktifkan batu ritual tersendiri di kanan dudukan; batu ini berbeda dari sumber pemulihan. Obor asli tampak melalui bentuk tengkorak UV; silang adalah umpan. Pancing api dalam jarak bidik sebelum menyiram. N/E/W masing-masing satu Blitz, Selatan hanya air, lalu satu Blitz inti di Pendopo. Sektor sukses tetap selesai setelah Continue.

Periksa Cermin Saksi di relung Barat: rekam ketukan, bidik mata tertutup dengan UV, putar roda, ambil dari laci. Arsip opsional. Setelah segel, pesan membuka gerbang kelima. Konfirmasi sebelum menuruni tangga; Continue CP8 kembali ke vestibule pada malam sama. Gameplay penuh Pasar Setan belum termasuk babak ini.

## Yang perlu dilaporkan dari playtest manusia

- Jalur/reticle yang sulit, posisi persis, checkpoint, nilai baterai/Sanity/air, serta apakah memakai OTS atau FP.
- Nyaman/tidaknya crouch dan HP, keterbacaan simbol pada720p, kepadatan/komposisi, material putih/pink atau collider tembus.
- Kejelasan peringatan Banaspati, dua kontak, grace setelah load, jeda refill/dinamo/shrine, serta kesempatan merespons sebelum serangan.
- FPS/frame-time mesin Windows asli: GPU/CPU/RAM, resolusi dan preset. Hasil Linux software renderer bukan benchmark IrisXe.
- Pacing, emosi/VO, konteks cerita dan kualitas visual dibanding referensi. Subtitle dan efek berlisensi telah disiapkan; akting VO manusia belum final.
