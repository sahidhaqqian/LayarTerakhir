# Playtest Atmaja — Adegan 2–3

Build dimulai di Kos approved. Selesaikan pembuka, atau lanjutkan save Atmaja yang sudah ada. Jangan menghapus save pemain untuk menguji; gunakan folder profil cadangan bila perlu. Jangan jalankan flag audit untuk playtest manual.

1. Keluar kos: fade harus memuat halaman Atmaja, bukan berhenti hitam. Gerbang E, periksa motor dan baca catatan survei. TAB angkat HP, klik MULAI LIVE. Siaran mulai 14 penonton; TAB/F tidak memutus siaran.
2. Susuri lorong timur: satu donasi terikat 500k. Berdiri terhalang kamboja; tahan CTRL sampai melewati batang. Dekati jendela dapur pecah, hadap ke dalam, SPACE vault. Jendela menutup; 250 penonton.
3. Dapur: sumur berantai, suara ketukan + teks bisikan (belum rekaman suara). Foto celah papan opsional: bonus sah 150k, hanya sekali. Buka pintu ruang makan. Merunduk di sisi ransel bawah meja, E ambil chip HP Damar. Hanya HP Raka yang dipakai.
4. TAB/Q: sosok ujung meja dan petunjuk waktu hanya terlihat di layar AR HP. Kamera biasa kosong. F mematikan gambar/kamera kedua, siaran tetap tersambung.
5. Ambil jarum kuningan di meja tamu. Periksa petunjuk AR di dekat tangga. E jam, masukkan 3-4-5 = 03:45, ATUR JAM. Baca koran 1998; kunci tangga hanya diberikan untuk waktu benar.
6. E pintu tangga: checkpoint lantai 1. Tutup dan buka ulang game: lanjut di Atmaja dengan item/baterai/uang tetap, bukan kos; donasi tidak boleh berulang. Lantai dua/Adegan 4–7 belum tersedia.

Uji tambahan: remap E/CTRL/SPACE/TAB/Q, coba keluar-muat saat koran belum ditutup, foto sumur dua kali, halangi raycast, turunkan baterai sampai 0 setelah powerbank habis. Port USB di motor dan charger dapur memulihkan ke 35% agar tidak softlock. ESC menutup modal sesuai HUD existing; TAB menyimpan HP jika belum ingin memulai live.

F12 menyimpan screenshot lewat utility development existing (lihat Screenshot-Guide.txt). Rekam bug dengan posisi, checkpoint, langkah reproduksi, Player.log dan screenshot. Ukur FPS/frame time/memori di Windows Iris Xe pada 1280×720; belum ada angka performa target yang tervalidasi di host Linux software-rendering.
